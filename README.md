# Ing. Sayo Koroma — Portfolio Website

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling and visual design
- `script.js` — mobile navigation and current footer year
- `assets/` — the two supplied portrait photographs

## View locally
1. Extract the ZIP file.
2. Open the `sayo_koroma_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

For the best development experience, open the folder in VS Code and use the Live Server extension.
